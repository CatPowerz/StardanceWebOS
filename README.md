# CatOS 2 (WebOS)

CatOS 2 is a retro-styled OS written in html/css/js, featuring three different apps and, above all, cute cats :)
The project is running at https://catpowerz.github.io/StardanceWebOS/ and is **fully handmade from scratch by me**.

# Features

- Notepad: write notes and save/load them locally.
- Pixel: an image of my cute cat named **Pixel**!
- CatAudio: an app to play my very own handmade soundtracks.
- Settings: change the appearence of the OS like background, font and background brightness/transparency.

You can drag windows around, and even fullscreen them!

**AI was barely used!**
Only Gemini was occasionally used for debugging specific formulas, but the README, the website itself etcetera was handmade. Even the music in CatAudio is one of my proud handmade works.

**No framework! Just pure static html/css/js. It’s live!**
https://catpowerz.github.io/StardanceWebOS/
